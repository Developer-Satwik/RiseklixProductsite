Riseklix product site deployment notes
=====================================

Canonical production source:
  https://github.com/Developer-Satwik/RiseklixProductsite
  branch: main

Production hosting target:
  Netlify

Required Netlify Git configuration:
  - Connect the repository Developer-Satwik/RiseklixProductsite
  - Production branch: main
  - Base directory: repository root
  - Build command: none
  - Publish directory: .
  - Functions directory comes from netlify.toml: netlify/functions

Important:
  - Do not use drag/drop ZIP deployment for normal production releases.
  - A manual Netlify snapshot can drift from GitHub and leave search engines crawling stale pages.
  - netlify.toml, _redirects, robots.txt and sitemap.xml are part of the production source and must deploy together with HTML/CSS/JS.
  - BEEHIIV_API_KEY must remain configured in Netlify environment variables for the newsletter function.
  - BEEHIIV_PUBLICATION_ID may also be configured in Netlify; the function currently contains a fallback publication ID.

Post-deploy verification:
  1. Confirm https://riseklix.com/ shows the Commercial Discovery homepage.
  2. Confirm /about/, /product/, /pricing/ and /resources/ match GitHub main.
  3. Confirm legacy .html URLs return 301 to their folder canonical URLs.
  4. Confirm /robots.txt and /sitemap.xml are current.
  5. Only after the new production version is live, submit important changed URLs for recrawling / IndexNow.

Legacy note:
  Earlier builds were distributed as ZIP files for manual Netlify deployment. That workflow is retired.
